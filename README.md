# 온클럽 공개 페이지

[온클럽(ONCLUB)](https://yahr.github.io/onclub/) — 유소년 스포츠클럽 운영 앱의 공개 페이지입니다.

| 페이지 | 주소 | 쓰임 |
|---|---|---|
| 소개 | `/` | 서비스 소개·링크 허브 |
| 지원 | `/support.html` | App Store 지원 URL · 심사지침 1.2의 공개 연락처 |
| 이용약관 | `/terms.html` | 부적절한 콘텐츠 무관용 조항 포함 |
| 개인정보처리방침 | `/privacy.html` | App Store · Play Console 필수 |
| 계정 삭제 | `/account-deletion.html` | Play 계정 삭제 요청 URL · 심사지침 5.1.1(v) |

**스토어에 등록된 주소라 경로를 바꾸지 않습니다.**

이 저장소는 앱 저장소에서 `tool/deploy_landing.sh` 로 생성·배포합니다. 여기서 직접 고치지 마세요.
